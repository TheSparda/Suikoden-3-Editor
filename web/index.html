Supports .ps2/.mcd memory cards, .psu, .psv, .cbs, SharkPort/.xps, and raw gamedata.

Edit the game disc directly — character growth, skills, runes, shops, spells, unite attacks, equipment and consumables; nothing is uploaded. On desktop Chromium edits are written in place; on Android/Firefox/Safari saving streams a patched copy to your downloads. Either way, back up first (or export a recipe).

Made by Sparda · GitHub · v1.5.2 Save editor: client-side Pyodide port of s3save.py (full parity, works everywhere). ISO editor: client-side port of s3patch.py/s3fields.py, in-place edits on Chromium desktop.
