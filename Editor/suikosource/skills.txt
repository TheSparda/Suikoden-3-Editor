Skill Descriptions

The following charts details what the skills actually do. The effects for each level are listed, as well as the basic uses of the skill. Mundane skills are the ones taught by the teachers, unique skills are skills that a character learns on their own

Swing	Mundane Skill
Allows multiple attacks in one round. Proficiency in this skill along with the weight of the weapon influences how many times a character can attack/round. What this skill actually does is decrease the "freeze time" after a weapon is used, and also to decrease the amount of time between each attack.

Combat Characters

This lists the skills each Combat Character can use in the game and the maximum level they can raise these skills up to.
Skills are divided into three types: Combat Skills, Magic Skills and Support Skills. Combat Skills must be raised at a Training Centre, Magic Skills at an Education Centre, and Support Skills cannot be raised. Not many Combat characters have Support Skills.
Characters have a set number of slots for skills that does vary from character to character. These come in two types: Fixed Skills which cannot be changed, and Free Skills that can; Free Skills can only be changed to one of the Mundane set that everyone can use. Fixed Skills are often from the Unique set, but may include some Mundane ones as well depending on character. Extra Fixed Skills are often gained as the character gains levels. Combat Character Support Skills are always of the Fixed type.
